# 3D design

This section includes all the 3D models for the project. Including files for the full 3d project, ready to print files and the 3d files for the PCB. The [`/printable`](./Printable/) folder includes ready to print files and the [`/FullProject`](./FullProject/) folder includes the full Fusion project files including the PCB, holder etc.

## Design choices

We wanted the holder to be as simple as possible and not take away from the main piece which is the PCB and the map on it. We wanted the holder to cover as little as possible while still being secure and holding the PCB well. We also didn't want any screws on the pcb at all so the case was designed to fit these criteria. The PCB is held in slots and no screws are used. On the front side the holder only covers small areas in each corner so the PCB stays very visible. We also plan to print it in a black filament which makes it blend in with the PCB better. Currently there is a wall mounted version that has a similar hole that is used for mounting picture frames on the wall. 

![3dRender](/media/FullRender.png)

The case is printed in 3 seperate pieces. The main body and then the top corners that are seperate pieces that slot into the main frame when mounting. So print the main frame in one piece and then slot in the PCB to it and then finally add the top corners to make the holder more secure and look better.
