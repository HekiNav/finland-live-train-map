# Build guide

We will go over part ordering and then hands on assembly.

## Ordering PCB

The PCB is the most expensive part of this project and it's ordered from a manufacturer like [JLCPCB](https://jlcpcb.com/). You should order the PCB assembled so as a PCBA. We included the gerber files required in the [`/pcb/gerbers`](./pcb/gerbers) folder. There is a minimum order amount of 5 so you will most likely have to order extra if you want to make this project.

## Ordering / printing the holder

Technically this project doesn't require a holder but if you want to hang this on the wall or having it stand on a desk you will need one. The wall mount is designed to be printed with minimal supports. It has slots for the PCB to slide into and it has a keyhole for mounting to the wall like a picture frame. You can either print this by yourself if you have a 3d printer or use a service like [JLC3DP](https://jlc3dp.com/). We had a printer we could use so we printed the holder ourselve. If you want more info about the design choices etc. for the holder check the [`3d files`](./3dFiles/README.md) section.
