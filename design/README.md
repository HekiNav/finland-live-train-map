# Map layout design
The layout of the map can be geographical or graphical
The SVGs in this directory are Inkscape SVGs

## Two options for map
### Geographical
`GeographicalMap.svg`
- Geographically accurate
- Recognisable
- Some distances between stations very short/long

### Graphical
`graph_v1.svg`
- More compact, saves on PCB costs
- Distances between stations more equal.

## Techical design
